## Structured musical input, authorized alongside speech preparation

Use existing `raagacomposer.core.models.Note`, `MelodyVersion`, `LyricLine` and `LyricsVersion`. `MelodyVersion` already retains structured notes and `audio_path`; continue preserving both. `voice_prototype.score_input.build_score_input` exports a serializable training/control boundary from these objects, rather than creating a competing melody model. Canonical note timings remain seconds; the export derives beat onsets/durations at explicit BPM, with a quarter note equal to one beat, eighth one-half and sixteenth one-quarter. Fractional MIDI, swara, raaga, tonic, gamaka labels, velocity and section references survive unchanged.

Explicit links name lyric line, syllable index and ordered note indices. Every supplied voice note and syllable must be linked exactly once and lyric order must survive. One syllable may cover multiple contiguous notes, including changing pitches (melisma). Ties join adjacent equal pitches within one syllable. Gaps and optional trailing silence become explicit rest events, which syllable spans cannot cross. Positive finite durations/tempo, no voice-note overlaps, correct melody version and valid references are required.

Optional articulation annotations reserve consonant onset/coda durations in beats and leave positive time for the vowel. These are declared controls, not phoneme boundaries inferred from the speech model. The initial adapter carries gamaka descriptions unchanged; it does not invent acoustic bend curves from a label. Existing `voice_prototype.tune.Event/Tune` remains the continuous-pitch rendering boundary.

`trials/make_score_input_example.py` provides an authored illustration of **அத நான் கத்துக்கிட்டு**, including one syllable over several notes, a same-pitch tie, fractional beat durations and rests. It is not an SPB performance transcription. This contract is implemented now as requested; training a model to obey it is a later singing extension. The present speech pilot remains speech-only. The adapter is not yet wired into product UI playback; this is a validated compatible input boundary and example.
